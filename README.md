# WeatherIP

Проект на Python: получает прогноз погоды и сохраняет его в базу данных.

## Что делает программа

1. Определяет ваш город по IP-адресу (через `ipinfo.io`).
2. Запрашивает прогноз погоды на 4 дня (сегодня + 3) у OpenWeatherMap.
3. Группирует 3-часовые интервалы в дневные сводки (мин/макс температура, влажность, ветер).
4. Сохраняет результат в базу SQLite.
5. Выгружает прогноз в файл `weather_report.md`.

Все настройки (ключи, URL, параметры БД) берутся из файла `.env`.

## Технологии

- Python 3.10+
- `requests` — HTTP-запросы к API
- `SQLAlchemy 2.x` — работа с базой данных
- `python-dotenv` — чтение `.env`
- SQLite — локальная база (файл создаётся сам)

## Установка

```bash
git clone https://github.com/<ваш_логин>/weather-etl-lab.git
cd weather-etl-lab

python -m venv .venv
source .venv/bin/activate        # Linux/macOS
.venv\Scripts\activate           # Windows

pip install -r requirements.txt
```

## Настройка

1. Скопируйте шаблон:
   ```bash
   cp .env.example .env         # Linux/macOS
   copy .env.example .env       # Windows
   ```

2. Зарегистрируйтесь на https://openweathermap.org/api и получите бесплатный API-ключ
   (раздел «API keys» в личном кабинете).

3. Откройте `.env` и впишите ключ:
   ```dotenv
   WEATHER_API_KEY=ваш_ключ_сюда
   ```

   Остальные переменные можно оставить по умолчанию.

**Важно:** новый ключ активируется в течение 10–60 минут. Если сразу после регистрации
получаете ошибку 401 — подождите и попробуйте снова.

## Запуск

```bash
python main.py
```

После запуска в папке появятся:
- `weather_lab.db` — файл базы данных;
- `weather_report.md` — отчёт с прогнозом.

## Пример вывода в консоль

```
Город:        Moscow
Координаты:   55.7520, 37.6178
Период:       2026-09-15 — 2026-09-18
Записей в БД: 4 (новых: 4)
Файл отчёта:  weather_report.md
```

## Пример `weather_report.md`

```markdown
# Прогноз погоды

Автоматически определённая локация: **Moscow**

Период: 2026-09-15 — 2026-09-18

| Дата | Мин. темп. | Макс. темп. | Описание | Влажность | Ветер |
|------|----------------|------------------|----------|---------------|-------------|
| 2026-09-15 | 8 | 14 | Облачно | 75 | 4.0 |
| 2026-09-16 | 6 | 13 | Дождь | 85 | 5.0 |
| 2026-09-17 | 5 | 11 | Пасмурно | 80 | 3.0 |
| 2026-09-18 | 7 | 15 | Переменная облачность | 70 | 2.0 |
```
